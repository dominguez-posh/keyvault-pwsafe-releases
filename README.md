# KeyVault PwSafe – Releases

Installer und Browser-Erweiterung von KeyVault PwSafe (Quellcode in einem privaten Repository).

- `KeyVault-PwSafe-Setup-<Version>.exe` – Desktop-App, Installation pro Benutzer ohne Administratorrechte
- `KvPwSafe-Geraet-Einrichten.ps1` – einmal pro Gerät (Intune-Plattformskript): Zertifikat des Windows-Passkey-Anbieters und Edge/Chrome-Richtlinie für die Erweiterung
- `kvpwsafe-extension.crx` / `update.xml` – Browser-Erweiterung, von Edge/Chrome über die Richtlinie automatisch geladen
